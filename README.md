# FIO API Multiplatform knihovna (Kotlin)

## Použití

1. Otevři projekt v IntelliJ/Android Studiu.
2. Zadej svůj API token v `example/src/main/kotlin/cz/gpt/fioexample/Main.kt` místo `<TVŮJ_FIO_API_TOKEN>`.
3. V rootu spusť:

```
./gradlew :example:run
```

Zobrazí se výpis pohybů na účtu (poslední změny).

### Knihovna je multiplatformní – můžeš použít v Android, iOS, JVM, JS projektech.
